# Requerimientos del Cliente

# Lista de Requisitos del Cliente (Requerimientos Identificados)

A partir de la información recolectada en las entrevistas de campo a los comercios, se estructuran los siguientes requerimientos utilizando identificadores únicos y lenguaje sencillo para el cliente:

---

## 1. Módulo de Registro y Cobro Rápido (POS)
* *RQ-01:* El sistema debe permitir al cajero seleccionar combos y productos mediante una interfaz táctil simplificada de botones grandes para agilizar la toma de pedidos en horas pico.
* *RQ-02:* El sistema debe calcular automáticamente el total a pagar y el cambio del cliente para evitar errores manuales durante el cobro.

---

## 2. Módulo de Personalización de Pedidos y Mermas
* *RQ-03:* El sistema debe permitir agregar modificadores a los productos (por ejemplo: "Sin cebolla", "Extra salsa") y transmitir estas notas directamente a la cocina para evitar equivocaciones en los platillos.
* *RQ-04:* El sistema debe registrar las anulaciones o mermas de productos justificando la razón de la pérdida para llevar un control estricto de insumos desperdiciados.

---

## 3. Módulo de Estandarización y Recetas
* *RQ-05:* El sistema debe descontar automáticamente del inventario la cantidad exacta de ingredientes requeridos por cada platillo vendido, basándose en la receta predefinida.

---

## 4. Módulo de Alertas de Stock y Reabastecimiento
* *RQ-06:* El sistema debe enviar alertas visuales al encargado cuando un ingrediente principal (por ejemplo: carne, tortillas, verduras) alcance su nivel mínimo de existencia, previniendo el desabasto.

---

## 5. Módulo de Reportes e Indicadores
* *RQ-07:* El sistema debe mostrar un resumen diario de ventas que identifique los platillos más vendidos y las horas con mayor afluencia de clientes.

---

## 6. Módulo de Seguridad y Accesos
* *RQ-08:* El sistema debe restringir las acciones sensibles (como cancelación de pedidos o aplicación de descuentos) únicamente a los usuarios con rol de Administrador/Encargado.
