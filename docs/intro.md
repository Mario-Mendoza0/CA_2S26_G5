# Introducción al Proyecto 2

#  Proyecto 2: Sistema POS Unificado y Gestión Operativa para Restaurantes

Bienvenido al **Proyecto 2** para el curso de **Comunicación Asertiva (Grupo 5)**[cite: 1, 9]. 

Este proyecto documenta la investigación, análisis y diseño de un ecosistema de software POS (*Point of Sale*) "Local-First" enfocado en optimizar el tiempo de atención, el control de inventario/mermas y la seguridad de transacciones en restaurantes de comida rápida y comercios afines[cite: 2, 8].
